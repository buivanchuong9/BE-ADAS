# Optimized Models Directory

This directory stores TensorRT engines and pruned models generated by the optimization scripts.

## How to generate optimized models

```bash
# Generate FP16 TensorRT engine (fast, recommended)
python3 scripts/optimize_models.py --model yolo11m --precision fp16

# Generate INT8 TensorRT engine (fastest, needs calibration data)
python3 scripts/optimize_models.py --model yolo11m --precision int8

# Full optimization: Prune 20% + INT8 quantization
python3 scripts/optimize_models.py --model yolo11x --prune 0.2 --precision int8
```

## Expected speedups

| Optimization | vs FP32 PyTorch | Notes |
|--------------|-----------------|-------|
| FP16 TensorRT | 2-3x faster | No calibration needed |
| INT8 TensorRT | 3-5x faster | Best with calibration images |
| Pruned + INT8 | 4-6x faster | Maximum throughput |

## Using optimized models

After generating an INT8 engine for yolo11m:

```bash
# Start worker with turbo profile
python3 workers/gpu_worker_simple.py --profile turbo --worker-id gpu0
```

## Files

- `yolo11m_int8.engine` - INT8 quantized YOLOv11m
- `yolo11m_fp16.engine` - FP16 quantized YOLOv11m
- `yolo11m_pruned_20pct.pt` - Pruned model (20% channels removed)
